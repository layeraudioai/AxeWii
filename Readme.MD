AxeWii
--
Use guitar hero guitars as midi instruments with soundfont rendering, sf2 import, midi import, and graded playback. Fine tune notes with the stick, strum with the strum bar, play individual frets, open notes, chords, and more.
--
Source (web app):
-
this is an aio index.html file. just download it and right click it and open with edge or edge. it should just work locally client side with no remote or local server hosting.
--
Source (monogame/c#):
-
see the AxeWii.MonoGame folder. compile it by opening the terminal inside that folder (or changing directory to it after opening the terminal elsewhere) by typing `dotnet build`. you need all obvious dependencies on the pc already.
--
Release:
-
this is an aio exe file. just download it and open it. it should work without installing, remote or server hosting, and also no external web browser needed.
